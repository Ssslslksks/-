这是一个使用Chatgpt制作的一个运动计时器，制作它是因为我需要系统化健身，而且市面上没有找到自己喜欢的计时器，刚好一哥们充了个Plus借我玩，就用AI自己设计一个。

这个计时器主打的是自定义外观背景与板块：选择背景图片，可以分别调整三个板块的颜色、透明度和毛玻璃模糊强度。

四种阶段提示音可分别选择本地音频，支持关闭及音量调节。所以你可以加入你喜欢的语音，塞个奶龙大笑或者哈基米曼波啥的。
